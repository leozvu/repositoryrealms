## Locked direction

- Enterprise clarity is primary; medieval-civic atmosphere is secondary.
- Use dark graphite, midnight navy, smoked oak, aged brass and restrained parchment highlights.
- Functional copy uses a modern humanist sans serif.
- Serif is restricted to the Realm brand display accent.
- Decoration is optional and never communicates state.
- No castles, crowns, shields, swords, armor, magic, quests, loot, tavern motifs or fantasy typography.
- No cyberpunk neon, purple SaaS gradients, toy-like cards or excessive glassmorphism.

## Sheet 01 prompt summary

Create an ultra-wide production design-system sheet using the accepted Realm board as a mandatory style reference. Isolate foundations and primitives into labeled sections: exact color roles and values, humanist-sans type scale, 8-point spacing, radii, borders, focus ring, density, surface elevation, core controls with interaction states, monoline functional icons and operational indicators. Preserve the medieval-civic feeling through restrained materials and manuscript-like dividers while keeping every component buildable in HTML/CSS and excluding RPG/fantasy imagery.

## Sheet 02 prompt summary

Create an ultra-wide application-shell specification sheet matching sheet 01. Isolate a 1440px desktop shell anatomy, expanded and collapsed navigation rails, top command bar, page-orientation controls, desktop/tablet/mobile contextual drawers, desktop/tablet/mobile shell adaptation, keyboard path, route focus, back-state restoration, deep links, motion and z-index. Use a maximum of five labeled mobile destinations, visible focus and 44px touch targets. Keep medieval-civic expression limited to restrained framing and material.

## Sheet 03 prompt summary

Create an ultra-wide work-object specification sheet matching sheets 01 and 02. Decompose semantic tokens, task, project, person/workload, approval, Action Center, message, notification, metric, table, queue, timeline and progress components. Show anatomy, compact/comfortable/mobile variants, canonical source and freshness, responsive priorities, loading, empty, error, stale, offline, permission-denied and redacted states. Prohibit employee scoring, ranking, surveillance and any business meaning carried only by decoration or color.

## Sheet 04 prompt summary

Create an ultra-wide command-safety specification sheet matching the prior sheets. Decompose tooltip, popover, dropdown, modal, drawer and mobile bottom sheet; authorized command palette; natural-language proposal and structured preview; command lifecycle; maker-checker approval; confirmation, destructive, unsaved and failure modals; inline, banner, toast and persistent feedback; canonical receipt and audit timeline. Make proposal, approval, execution and confirmation visibly distinct, and never show success without a canonical receipt.

## Sheet 05 prompt summary

Create the operational grammar for Realm: nine page templates, standard page anatomy, task/command/approval/incident/collaboration lifecycles, responsive desktop/tablet/mobile composition, resilience states and non-negotiable accessibility and receipt rules.

## Product boards 06–14 prompt summary

Compose the complete Realm application ecosystem from the locked system: personal home/work; team flow/action triage; command/approval governance; inbox/collaboration; project/Chronicle; federation map/CEO terminal; people/recognition; settings/search/notifications; and a priority-first mobile suite. Each board includes responsive adaptation, state specimens, source/provenance, authorization and canonical-receipt behavior. Preserve medieval-civic character through proportion and restrained materials only, never through RPG mechanics or business-state decoration.
